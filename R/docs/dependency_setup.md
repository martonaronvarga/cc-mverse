# Dependency Setup And Report

Dependency reports are generated by:

```sh
Rscript R/bin/write_dependency_report.R R/outputs/analysis
```

Fail early with actionable dependency errors:

```sh
Rscript R/bin/check_dependencies.R
```

Generated artifacts:

- `R/outputs/analysis/dependency_report_r_packages.csv`
- `R/outputs/analysis/dependency_report_tools.csv`
- `R/outputs/analysis/dependency_report_rust.csv`

## Policy

- Do not install packages at runtime inside analysis scripts.
- Fail early if required packages are unavailable.
- Record R package versions, R version, Rust compiler version, Cargo version, Cargo manifest path, and Cargo lock presence before interpreting full audit results.
- Treat dependency/version changes as invalidating processed Rust outputs and model/result summaries.
- Keep Arrow/parquet compatibility explicit because processed branch files cross the Rust/R boundary.
