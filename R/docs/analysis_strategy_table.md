# Analysis Strategy Table

The operating-characteristics work evaluates CSE as the common location interaction `cong:prev_cong`. The strategy table is machine-readable at `R/outputs/analysis/analysis_strategy_table.csv` and is generated by:

```sh
Rscript R/bin/write_analysis_strategy_table.R R/outputs/analysis/analysis_strategy_table.csv
```

## Included strategy families

- `rmANOVA`: participant-level 2x2 cell means on raw RT and log RT.
- `basic_lm`: trial-level fixed-effect regression with participant fixed effects, raw RT and log RT.
- `LMM`: random-intercept and maximal by-participant random-effects variants, raw RT and log RT.

## Common extraction rule

The CSE term must be selected by exact name:

```text
cong:prev_cong
prev_cong:cong
```

Do not select the first coefficient containing `:` and do not select rmANOVA rows by position.

## Denominator rule

Every strategy contributes to the unconditional FPR/TPR denominator when planned. Conditional rates are sensitivity summaries among numerically usable fits only. Failure-aware summaries must report significant, usable nonsignificant, singular, non-converged, extraction/preprocessing error, and missing-p categories.

## Current status

This table defines the intended strategy set for known-null/known-alternative operating-characteristic implementation. It does not modify the existing core config or model fitting code.
